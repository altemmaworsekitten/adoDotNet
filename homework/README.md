# Домашние задания

Одно домашнее задание — одна папка `NN-<тема>`: номер двумя цифрами и тема английскими словами через `-`.
Когда задание выдано, преподаватель дописывает строку в таблицу ниже. Имя папки берите из таблицы.

| Папка | Задание | Срок |
|---|---|---|
| — | заданий пока нет | — |

## Что лежит в папке ДЗ

| Файл | Что в нём |
|---|---|
| `README.md` | что задано, как запустить, пример вывода программы |
| папка проекта, например `OrdersReport/` | проект C#, создаётся командой `dotnet new console -n OrdersReport` |

Чтобы проект работал с базой, в его папке выполняется `dotnet add package Npgsql`.
Строка подключения та же, что в заготовках практических работ: `Host=localhost;Port=5433;Database=orders;Username=student;Password=student`.

## Как сдать

1. Создайте папку с именем из таблицы, например `homework/01-orders-report`.
2. Создайте в ней проект и `README.md`.
3. Запустите программу и сверьте вывод с заданием.
4. Сделайте коммит `homework 01: отчёт по заказам` и отправьте его на GitHub
   (порядок — в [`docs/SUBMIT.md`](../docs/SUBMIT.md)).
